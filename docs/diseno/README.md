# Documentos de diseño de referencia

Documentos del usuario que sirven de diseño, no de datos del juego: el juego no los lee. Cuando algo de aquí choca con una decisión de `../DECISIONES.md`, manda la decisión.

| Archivo | Qué es |
|---|---|
| `addon_futbol_v2.1.json` | Addon de fútbol 2.1 (posiciones, roles, habilidades con sus secundarias, afinidades, motor del partido, competición). Ids en inglés: los del juego están en español (`../ANALISIS_FUTBOL.md` §4) |
| `diseno_stats_personalidad_v0.2.md` | Diseño de stats, perks y personalidad v0.2 (del proyecto original en Godot; nombre original `desing_stats_personality_system.md`). Base del `../BACKLOG_STATS.md` |

Lo que se adapta, se descarta o choca con el juego, y por qué: `../ANALISIS_FUTBOL.md` §0 y §3.
